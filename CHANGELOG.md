# Changelog

## 2.5.0 - 2026-10-10

Initial release of DoD Sandbags.

- Opt-in sandbag building with held-key previews and release-to-place controls.
- Elongated 64 x 32 x 16 bags with 90-degree rotation, stacking and straight-row
  snapping.
- Player collision and destructible cover; ten pistol hits at default settings.
- Configurable global/per-player quotas, cooldown, reach, health, pistol damage,
  lifetime, disconnect cleanup, admin access, entity reserve and preview opacity.
- Own-bag removal, administrator clear and server diagnostics.
- Automatic AMXX configuration and English messages with translation support.
- Source code, model generator and installation documentation.
